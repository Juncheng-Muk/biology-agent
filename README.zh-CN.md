# Biology Agent

**面向生物信息学与组学、重视研究设计的科研协调技能。**

[English](README.md) · [架构说明](docs/architecture.md) · [体验示例](examples/README.md) · [验证记录](docs/validation.md)

Biology Agent 将生物学问题组织成可检查的研究任务：确认实验设计、审计输入、选择分析方法、核验生物学证据，再形成图表与论文材料。

项目以 **Codex skill** 形式实现，包含协调规则、领域参考、合成示例和文件校验工具。语言模型、执行工具与子 agent 能力由宿主提供；当前成果是可复用的研究协调协议。

## 为什么先检查研究设计

分析代码能够运行，不代表结论成立。大量细胞不能替代独立供体；分组与批次完全重合时，整合算法无法识别独立的分组效应；通路富集也不直接证明因果机制。

Biology Agent 把这些判断放在统计推断之前，并要求它们贯穿结果解释与写作。

## 主要能力

| 工作 | 重点 |
| --- | --- |
| 样本与数据审计 | 独立重复、配对关系、混杂、元数据与矩阵含义 |
| 组学分析协调 | 沿用 R/Python 项目环境，记录输入、参数、版本和执行状态 |
| 文献与生物学解释 | 核验来源，区分观测、关联、解释和机制假说 |
| 图表与科研表达 | 核对图表、统计结果、图注、正文和方法的一致性 |
| 独立复核 | 对复杂或重要结论提出可定位、可修复的问题 |

领域参考涵盖 bulk RNA-seq、单细胞/单核 RNA-seq、空间组学、表观组/变异分析、蛋白组/代谢组和多组学整合。这些是分析决策指导，具体项目仍需相应数据、工具和验证。

按任务启用文献、数据审计、分析、解释、写作与复核角色。可独立的工作在宿主支持时并行；统计推断等待设计检查，结果写作等待结果核验。简单问题由协调者直接处理。详见[架构说明](docs/architecture.md)。

## 安装与调用

在尚未存在同名技能目录时运行：

```bash
mkdir -p ~/.codex/skills
git clone https://github.com/Juncheng-Muk/biology-agent.git ~/.codex/skills/biology-agent
```

已有安装时先检查原内容，再决定是否更新。

在能够发现此技能的 Codex 聊天中输入：

```text
$biology-agent
帮我检查单细胞项目，再制定差异表达方案。
数据路径：/path/to/project
研究问题：B 组相比 A 组，各细胞类型的表达是否发生变化？
先核对供体、批次、分组和矩阵层，说明当前设计支持哪些结论。
```

默认中文回复，也可要求英文。其他宿主可将 Markdown 作为任务指导，但工具和多 agent 调度需要自行适配。主文件中提到的其他专门技能为可选扩展，本仓库未捆绑提供。

## 无需真实数据的体验示例

[合成研究设计审计](examples/README.md)提供 6 位虚构供体、两组各 3 位、合计 50,000 个虚构细胞计数。A 组全部来自批次 1，B 组全部来自批次 2。

示例检查 agent 能否识别伪重复与完全混杂，并给出当前可做的检查和后续设计建议。它没有表达矩阵，不产生基因效应、P 值或生物学发现。可查看[一次人工试用的原始答复和审查记录](docs/validation.md)。

## 本地文件校验

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python scripts/validate.py
```

校验范围包括技能元数据、相对链接及示例表格的一致性。它不调用模型，也不替代真实组学数据上的方法验证。

## 项目状态

初版在 AI 辅助下开发，展示任务拆解、研究设计判断、依赖管理和证据追踪。当前未声称真实数据基准成绩或生物学发现。独立审查的真实案例、跨模型重复评估和可执行工作流适配器是后续方向。
