# 组学分析：按数据状态和设计选择方法

本文件用于分析方案、代码实施与结果复核。它不是固定工具链；先沿用项目环境。需要查方法适用性、参数或软件接口时，核对对应版本的官方文档或原始方法论文。未检索时不要宣称使用了“最新版”或“最佳方法”。

## 通用入口与复现

- 清点输入格式、大小、样本数、特征数、标识体系、数据来源和元数据关联键。确认矩阵方向、稀疏性、计数/对数/标准化状态，不凭文件扩展名推断数据含义。
- 检查样本 ID 唯一性、缺失、重复、合并键基数、分组与批次关系。确认配对、纵向、家系或嵌套结构；保留可追溯的样本表。
- 为主要比较明确实验单位、对比方向、协变量、适用模型及可识别性。缺乏独立重复时，允许描述和探索，限制群体层面显著性推断。
- 在变换或合并前核对基因组、注释、坐标约定和 feature ID 版本。基因符号映射需记录一对多、未映射及被丢弃的条目。
- 原始数据只读；派生对象另存。可利用现有工作流的缓存/检查点。大规模运行前先小样本检查格式、依赖、内存与磁盘需求，但不能把小样本检查当作全流程成功。
- 记录环境文件或依赖版本、执行命令、参考资源、参数、随机种子和关键运行日志；只声称实际验证过的可复现性。

## bulk RNA-seq / 转录组

- FASTQ 起点与计数矩阵起点是不同任务；只有 FASTQ 分析才能报告 reads 层面的质控、比对或定量指标。核实测序布局、链特异性及参考资源后选择定量路线。
- 区分整数 counts、带偏移/长度校正的估计计数和 TPM/FPKM/log 表达；不得把标准化连续值直接当作原始计数输入不适配的模型。使用定量结果导入方案时说明其假设。
- 根据设计处理低表达、文库差异、配对与协变量；先检查样本层面结构和异常，再解释差异。PCA 等探索图本身不构成删样本理由。
- 结果保留 feature ID、contrast、效应方向/大小、标准误或区间（若方法支持）、原始与校正 P 值、过滤规则；避免只导出“显著基因”。

## 单细胞 / 单核 RNA-seq

- 检查供体—样本—文库—细胞的关系，以及 QC、doublet/ambient RNA 处理是否适用、是否已经执行。指标阈值由组织、物种、平台和分布决定，不能套固定线粒体比例。
- 保留原始 counts、细胞条码和来源；核对对象中的 assay/layer 含义。整合/批次校正表示用于相应的表示学习任务，不自动替代差异表达需要的数据和模型。
- 同时检查整合后的批次混合与生物信号保留。条件与批次完全混杂、共享细胞类型不足时，不以“混得更好”作为唯一质量指标。
- 细胞注释综合多个阳性/阴性 marker、组织背景、参考映射和供体一致性；允许保留未知/混合标签，不从单一 marker 断言新亚群。
- 组间差异以供体/独立样本为推断基础；可按细胞类型×样本聚合的 pseudobulk 或合理的层级模型处理重复。先检查每个组合的细胞量、缺失和模型条件，再选择方法。
- 区分细胞丰度变化与细胞内表达变化；考虑样本层面组成约束。轨迹、RNA velocity 和通讯分析是带模型假设的探索证据，不自动代表真实时间、谱系或已验证互作。

## 空间组学

- 核对图像、空间坐标、尺度、切片、spot/细胞 ID 的匹配与组织覆盖；区分 spot 混合表达与单细胞分辨率。
- 建模时考虑空间自相关以及供体/切片嵌套；相邻 spot 不能随意视为独立生物学重复。考虑设计支持的空间约束置换或层级方法。
- 解卷积、空间域和配体–受体共定位结果均需报告参考、分辨率及假设；共定位不证明细胞通讯。

## ATAC-seq / 表观组学与变异分析

- 按任务检查参考版本、区间坐标制式、重复/背景信号、适用的 QC 指标和特征空间一致性。只有存在对应输入时才计算该层级指标。
- 峰到基因关联、motif 富集和可及性不等于转录因子实际结合或靶基因调控；说明链接方法和可替代解释。
- 变异分析核对样本身份、覆盖/质量、callability、倍性和注释版本；群体比较考虑亲缘与群体结构。预测致病性不能直接转为临床诊断。

## 蛋白组 / 代谢组

- 核查批次、空白/质控样本、单位、鉴定置信度和缺失机制。不同鉴定层级的分子/feature 不混为同一确定身份。
- 不默认用零填补或单一插补解释所有缺失；区分低于检测限、随机缺失和真实缺失的可能，评估结论对处理方式的敏感性。
- 说明归一化、批次处理和多重检验范围；涉及共享肽或不唯一代谢物鉴定时保留歧义。

## 多组学整合与预测

- 先确定是否来自同一受试者、同一时间/组织，或仅有群体层面的对应。未配对数据不能伪装成逐样本联合矩阵；记录 ID 映射和缺失模态。
- 先分别检查各模态质量、尺度和批次，再选早期/潜变量/后期整合等方案。描述共同结构与模态特异结构；潜因子本身不是机制。
- 预测任务按受试者及必要的中心/时间分割，预处理、插补、特征选择和调参在训练折内部进行；按需采用嵌套交叉验证和独立验证。报告校准和不确定性，不能只给训练集准确率。
- 对关键发现做与风险匹配的敏感性或独立数据检查；无独立验证时如实保留限制。

## 功能解释和结果一致性

- 富集分析记录物种、标识映射、基因集来源/版本、实际被检测且有机会入选的背景、排序统计量及多重检验方法。对所有基因使用默认背景可能引入偏差。
- 区分过度代表分析与排序富集的输入要求；避免将通路条目数量当作相互独立证据。通路方向、成员基因和可检测性共同决定可支持的表述。
- 交付前核对图、表、正文的样本数、对比方向、效应量、显著性阈值和排除规则；生成图不能代替检查底层结果。
